zengin-api

全銀フォーマット（金融機関コード・支店コード）を提供する読み取り専用JSON API。

API v1

  • GET /v1/banks — 金融機関一覧（?q=で部分一致検索）
  • GET /v1/banks/{code} — 金融機関を1件取得
  • GET /v1/banks/{code}/branches — 指定金融機関の支店一覧（?q=で部分一致検索）
  • GET /v1/banks/{code}/branches/{branchCode} — 支店を1件取得
  • GET /v1/branches — 全支店（?bank_code= / ?q=で絞り込み）

ヘルスチェック

  • GET /healthz

ドキュメント

  • GET /openapi.json — OpenAPI 3.0仕様
  • GET /docs — Swagger UI

AIエージェント向け

  • GET /ai — 概要・エンドポイント一覧
  • GET /ai/concepts — ドメイン概念
  • GET /ai/guides — ユースケース別の実装手順
  • GET /ai/examples — リクエスト/レスポンス例
